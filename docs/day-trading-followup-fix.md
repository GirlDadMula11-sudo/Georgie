# Day-trading follow-up regression

This branch fixes the live iPhone regression where a short investment follow-up such as “What about day trading?” was still routed through the heavyweight durable-task path and the stale PWA shell displayed Sierra-only progress language.

Production acceptance requires: early investment response before orchestration, preservation of recent budget context, hidden execution panel for ordinary chat, no Sierra-only receipt text, and a PWA shell cache version bump.
